About Rishi

Full-stack roots, AI-first focus. I like turning a promising model into something people can actually use every day.

I started as a full-stack developer, building a multi-app Learning Management System in React and Node.js. Along the way I built its AI course generator, a RAG system that turns a prompt or an uploaded PDF into a structured course, and it became the default way instructors create content.

My approach is practical: ship it, measure it, make it better.

CodeGuardian AI

AI pull-request reviewer for GitHub

Connects to GitHub, pulls up any PR and reviews the diff as a first-pass reviewer would, going further than a generic linter.

  • GitHub OAuth + PAT sign-in to browse repos and inspect code changes in real time, without switching back to GitHub.
  • Repository sync, a history of past AI reviews, repo-level health analytics and per-repo reviewer settings.
